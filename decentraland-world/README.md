# Friendzone 3D World (SDK7)

This directory is the **actual Decentraland World**. The Expo app in the repository root is a 2D companion. It is not the Decentraland renderer.

- SDK: `@dcl/sdk` (SDK7). Do not mix `decentraland-ecs`.
- Entry: `src/index.ts`
- Config: `scene.json` (`runtimeVersion: 7`)
- World name: placeholder `YOUR_WORLD_NAME.dcl.eth` — replace before publish.

```bash
npm install
npm run start
npm run build
npm run validate
```
